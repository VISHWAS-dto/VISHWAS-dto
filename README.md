## 🏗️ Projects That Actually Ship

### 🔁 Human-in-the-Loop LLM Chatbot
**[`VISHWAS-dto/Human-in-the-Loop-LLM-Chatbot-with-LangChain`](https://github.com/VISHWAS-dto/Human-in-the-Loop-LLM-Chatbot-with-LangChain)**

Most LLM apps trust the model blindly. This one doesn't.

- Built with **LangGraph + NVIDIA NIM** — interrupt-driven execution with human validation gates
- Stateful conversation memory with dynamic context injection
- Approval-based response control: the agent pauses, humans verify, then it proceeds
- **Why it matters:** Safer AI isn't about weaker AI — it's about the right architecture

```
User → LLM Agent → [INTERRUPT] → Human Review → [APPROVE/REJECT] → Response
                        ↑_______________________________________________|
```
